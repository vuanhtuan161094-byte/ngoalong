## Status meanings

- **DONE** — the named, bounded behavior has runtime evidence; it does not mean the whole Mobile feature is complete.
- **PARTIAL** — a real path exists, with material content, art, balance, or device gaps.
- **REFERENCE_ONLY** — research records exist but are not connected to player behavior.
- **MISSING** — no qualifying runtime behavior is present.
- **BLOCKED** — progress requires external access or owner input.
- **SIMULATED** — project-authored rule/number or offline substitute; always remains distinct from verified source facts.
