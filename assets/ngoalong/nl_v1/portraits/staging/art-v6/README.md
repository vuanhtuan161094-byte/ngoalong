# Ngọa Long Art V6 — Production Batches

## Batch 1

24 full-body character masters styled to the owner-approved Tào Tháo / Mã Siêu V5 direction. Characters have distinct facial cues, hairstyles, silhouettes and poses, including standing, kneeling, dance, weapon action and relaxed floor poses. All are represented as clearly adult women aged 18 by owner direction, in bold fantasy lingerie/cosplay with exposed midriffs and thighs, thigh-high stockings and garters; breasts and groin remain covered.

Each character has a 1024x1536 PNG master, same-size runtime WebP, 768x768 portrait crop, and verbatim generation prompt with output ID, source references and hashes. The 11 runtime-adapted V6 heroes load their WebPs by local repository-relative paths, so the asset directory must stay beside `index.html`; the app remains usable offline from the repo checkout. See the manifest for exact files and source mappings.

The Mobile Wiki identifies these rows as reference-only. Eleven identities are also in the separate explicit runtime-adapter manifest; only those eleven receive art in the existing hero screens. The other thirteen remain reference-only. Art does not change recruitability or game mechanics.
